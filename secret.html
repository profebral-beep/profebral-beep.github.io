How it works

1. Write

Use simple pseudo-code: IF / THEN / ELSE, $variables, and methods like openInkarnate().

2. Set permissions

Each file declares what the AI may do (read, execute, create, edit, move). Anything not allowed is denied, and Denied beats Allowed.

3. Load and trigger

Files load first and run only when a trigger fires, such as "when asked to open inkarnate."

4. Pilot and co-pilot

The AI asks before guessing, reports "Done" when a step finishes, and waits for your approval on actions like moving the mouse.
